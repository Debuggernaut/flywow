This uses the MaleCNS project's scan of a fly's brain, read more about that here:

https://male-cns.janelia.org/

It captures your monitor's contents, then processes it into a format that could 
plausibly reach a fly's optical lobe neurons, and stimulates simulated copies of
those neurons with that input.  Then by adjusting the gain levels on the neurons
between the optical lobes through the visual processing neurons and descending
motor neurons to stimulate the legs' neurons.  It reads the neuron activity on
the leg neurons, then translates those into button presses.

I removed the code to send the button presses back to the WoW client directly,
since I think there's a pretty solid chance you'll get banned for running it as
it's a violation of the game's terms of service (either "Account Sharing" or
"botting" depending on whether you feel like the 'simulated fly' is alive)
